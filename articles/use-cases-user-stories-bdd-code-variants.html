На этой странице шесть вариантов одного и того же блока. Размер текста в вариантах соответствует основному тексту статьи. Вариант F добавлен по вашему скриншоту с оливковым фоном и жёлто-бирюзовой палитрой.

A. Светло-серый фон и чёрный текст

Самый близкий к вашему предложению: минимальный контраст с основным текстом, спокойная рамка.

Feature: Импорт банковской выписки

  Rule: Операция не импортируется повторно

    Scenario: Повторная загрузка операции
      Given счёт "KZ-01" содержит операцию "A-100"
      When бухгалтер импортирует операцию "A-100"
      Then новая операция не создаётся
      And результат содержит 1 дубль
